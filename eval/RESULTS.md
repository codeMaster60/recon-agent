# Evaluation results

Generated by `python eval/run_eval.py`. Each seed is one synthetic month (~320 orders, ~85 bank rows)
with 22 injected problems; every seed is checked against bank layouts a, b, c and d.

**Read this honestly:** the generator and the detector were written by the same person, so "clean"
mode mostly proves the rules do what they claim. "Hard" mode adds mess I didn't tune the rules
against first (bank posting lag of 0-3 days, 30% of narrations cut before the UTR). Real merchant
exports are the actual test.

Layout d has Hindi headers. Rules can't map it by design; it is the case the LLM path exists for.
Run `python eval/run_eval.py --llm` with `GROQ_API_KEY` set to measure that path.
